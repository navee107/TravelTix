## 🌟 Overview

**TravelTix** is a premium, fully responsive landing page designed for modern travel agencies and booking platforms. It features a sleek glassmorphism UI, smooth scroll navigation, and fluid animations to provide an immersive user experience. 

Whether users are looking for flights, trains, or buses, TravelTix offers an intuitive search interface and beautifully showcases featured destinations and popular travel packages.

## ✨ Key Features

- **🎨 Modern UI/UX:** Clean, professional design utilizing glassmorphism and a carefully selected color palette.
- **📱 Fully Responsive:** Flawless experience across all devices (Desktop, Tablet, Mobile).
- **✨ Fluid Animations:** Scroll-triggered animations and micro-interactions powered by `motion/react`.
- **🔍 Dynamic Search Form:** Interactive tabbed search interface for Flights, Trains, and Buses.
- **🧭 Smooth Navigation:** Sticky navbar with smooth scrolling to page sections and active state handling.
- **⚡ Blazing Fast:** Built with Vite and React for optimal performance and rapid development.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://reactjs.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Motion (Framer Motion)](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have Node.js installed on your machine.
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/traveltix.git
   cd traveltix
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` (or the port specified in your terminal) to view the application.
